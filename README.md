## Apps you can use

[![Magic Pantry 2 on the App Store. A shared Trader Joe’s list with Honeycrisp apples and baby spinach.](./assets/magic-pantry.png)](https://apps.apple.com/us/app/magic-pantry-2/id6757911019)

**Magic Pantry 2** keeps a shared grocery list for each store and sorts it by aisle. You can check off the apples in a dead zone and the change will sync when you get reception again. [Get Magic Pantry 2](https://apps.apple.com/us/app/magic-pantry-2/id6757911019)

**Tikset** is a clock for setting your watch. It checks your computer against network time and shows how far ahead or behind it’s running. [Check your clock](https://tikset.com/)

## Developer tools

<a href="https://www.qubetx.com/#products">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="./assets/releases-dark.png">
    <img src="./assets/releases-light.png" alt="Qube TX public releases, June 1 through November 20, 2026. Machine Report, 12. Network Diagnostics, 24. System Diagnostics, 15.">
  </picture>
</a>

**Qube TX** is where I publish my Rust diagnostics. Each square above is a public release from June 1 through November 20, 2026.

- [TR-300 · Machine Report](https://github.com/QubeTX/qube-machine-report) inventories the hardware and OS on the machine in front of you.
- [ND-300 · Network Diagnostics](https://github.com/QubeTX/qube-network-diagnostics) helps track down where a connection is failing.
- [SD-300 · System Diagnostics](https://github.com/QubeTX/qube-system-diagnostics) checks system health from the terminal or desktop.

**shaughv-code** collects the skills I use with Codex and Claude Code for debugging, handoffs, and release notes. I built **shaughv-tasks** alongside it so the next session can pick up where I left off. [Browse the skills](https://github.com/RealEmmettS/shaughv-code) · [Open the task board repo](https://github.com/RealEmmettS/shaughv-tasks)

**Occupancy Forecast** is a Home Assistant add-on I maintain as a fork. It predicts who’ll be home over the next 48 hours. Its local journal lets me compare a prediction with who actually showed up. [Explore the add-on](https://github.com/RealEmmettS/hass-occupancy)
